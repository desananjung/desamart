# 🌾 DesaMart

**DesaMart** adalah platform digital terpadu yang dirancang untuk mendukung transformasi digital desa melalui marketplace lokal, pemberdayaan UMKM, koperasi digital, layanan pemerintahan desa, dan sektor pertanian dalam satu aplikasi.

---

## 📖 Tentang Proyek

DesaMart dikembangkan sebagai platform yang dapat membantu pemerintah desa, pelaku UMKM, koperasi, petani, dan masyarakat dalam melakukan aktivitas ekonomi serta pelayanan desa secara digital.

Tujuan utama DesaMart adalah:

* Meningkatkan ekonomi desa.
* Mendukung digitalisasi UMKM.
* Mengembangkan koperasi digital.
* Mempermudah pelayanan desa.
* Menghubungkan masyarakat dengan produk lokal.
* Menjadi fondasi Smart Village berbasis teknologi.

# 🚀 Instalasi

## Clone Repository

```bash
git clone https://github.com/desananjung/desamart.git
cd desamart
```

---

## Backend

```bash
cd backend
npm install
```

Buat file `.env` sesuai kebutuhan, kemudian jalankan:

```bash
npm run dev
```

---

## Frontend

```bash
cd frontend
npm install
npm start
```

---

## Menggunakan Docker

```bash
docker-compose up -d
```
